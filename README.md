# AMSTools
Apliakasi Sistem Pencatatan Transaksi, Invoice &amp; Surat Jalan Multi-Tenant

## Requirements

Node.js 18.18 or newer. Node.js 20 LTS is recommended for local development and for the server that hosts this app.

## Backup

Back up the MySQL database and the `uploads/` folder together. Proof photos are files on disk, not rows in MySQL. See [docs/BACKUP.md](docs/BACKUP.md).
